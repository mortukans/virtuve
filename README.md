# Virtuve

**Ko ēdam šovakar?** Nofotografē ledusskapi — Virtuve pateiks, ko pagatavot no tā, kas
tev jau ir mājās.

Virtuve is a Latvian household food assistant for iOS. One household shares a virtual
fridge, a shopping list and a meal plan; each member has their own tastes and
allergies. The core loop:

1. **Scan the fridge** — the camera recognises your groceries (with confidence, you
   correct the rest).
2. **"Ko ēdam?"** — AI suggests 3 dinners built from what you already have, respecting
   everyone's preferences, the time you have, and what needs using up soon.
3. **Dinner Match** — the household swipes/votes; when you agree, cook mode walks you
   through it step by step.
4. **Shared shopping list** — missing ingredients are added automatically and sync live
   between members.

Less deciding. Less wasted food. Fewer arguments about dinner.

Built with Expo + Supabase (EU) + Claude. Latvian only. See [SETUP.md](SETUP.md) to run
it and [CLAUDE.md](CLAUDE.md) for the repo map.
